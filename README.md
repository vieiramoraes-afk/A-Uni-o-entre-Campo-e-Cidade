# 🌱 A União entre Campo e Cidade

Projeto desenvolvido com o objetivo de demonstrar a importância da conexão entre o campo e a cidade, destacando como ambos dependem um do outro para o desenvolvimento econômico, social e sustentável.

## 📖 Sobre o Projeto

O site "A União entre Campo e Cidade" apresenta informações educativas sobre a relação entre as áreas rurais e urbanas, mostrando como a produção agrícola, o comércio, a tecnologia e os serviços criam uma rede de interdependência essencial para a sociedade.

A plataforma busca conscientizar estudantes e visitantes sobre:

- A importância da agricultura para o abastecimento das cidades;
- O papel da tecnologia no desenvolvimento rural;
- A troca de recursos e serviços entre campo e cidade;
- A valorização do trabalho dos produtores rurais;
- A sustentabilidade e o desenvolvimento regional.

## 🚀 Funcionalidades

- Página inicial informativa;
- Conteúdo educativo sobre o campo e a cidade;
- Layout responsivo;
- Navegação simples e intuitiva;
- Recursos visuais para facilitar a compreensão do tema.
